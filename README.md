# NUXO Care landing page

A clean static Vite React site for the NUXO landing page.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## GitHub Pages

GitHub Actions builds the site with `npm run build` and publishes the generated `dist/` folder to Pages.

The site is fully static and uses the public logo in `public/nuxo-logo.jpg` plus direct phone and WhatsApp links for contact.
